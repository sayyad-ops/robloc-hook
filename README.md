# Luna

Cherry blossom automation for Steal an Egg.

## Features

- Auto steal, auto event, auto hatch, auto treadmill
- Auto combat — Rift bosses, Dr. Scramble's mech, Great Bloom crystals
- Server hop with passive / balanced / aggressive presets
- Target hunt — pick any of 110+ eggs, auto-hops until it finds a server where it's available
- Auto-return to base after steal — teleport / hybrid / walk
- Cherry blossom UI with petal bursts, ripples, ambient petals, sound effects
- RightShift kill switch
